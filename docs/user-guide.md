# User guide — how to use the Sports Car Build Library

For readers. No account, no app, no sign-in.

## Finding a car

The library page lists every build as a card: year, make, model,
chassis, engine, and a status pill — **In progress** (being built
now), **Template** (a slot waiting for a build page), or **Complete**
(finished). Click a card to open that car's page.

## Reading a build page

Every car follows the same layout:

- **Spec sheet** — factory figures for that exact vehicle.
- **The build so far** — where the car is now and what is next.
- **Build log** — dated entries, one per work session, newest
  first. This is the detailed record.
- **Parts list** — every part, with part number, source, price,
  and status (fitted / ordered / wanted / removed).
- **Gallery** — captioned photos from the build.
- **Changelog** — what changed on the page and the car, newest
  first.

## What "as stated" means

A figure marked "as stated" comes from a video, a forum, or memory
and has not yet been verified against the factory service manual.
Treat it as a lead, not a specification. Figures without that label
are factory figures or the builder's own measurements.

## Following updates

New builds and major updates go into the **RSS feed**
(`feed.xml`, linked at the top of every page). Subscribe in any feed
reader — there is no account to make and no platform in the middle.
The feed is a plain file on the same site; if the site moves, the
feed moves with it.

## Using the information

This is educational information from real garage work. Confirm
every specification in the factory service manual for your exact
vehicle before you buy parts or cut metal. If a measurement is
borderline, that is a decision point — not a reason to force a build
together.
