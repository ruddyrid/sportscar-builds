# User guide — how to use the Sports Car Build Library

For readers. No account, no app, no sign-in.

## Finding a car

The library page lists every build as a card: year, make, model,
chassis, engine, and a status pill — **In progress** (being built
now), **Template** (a slot waiting for a build page), or **Complete**
(finished). In progress and Complete cards link to that car's page.
Template cards are empty slots; there is nothing to open yet.

## Reading a build page

Every car follows the same layout:

- **Spec sheet** — factory figures for that exact vehicle. A figure
  the builder has not yet confirmed is marked "verify in FSM" (see
  below).
- **The build so far** — where the car is now and what is next.
- **Build log** — session entries, newest first, with dates where
  they exist. Video records with no confirmed date are kept as a
  separate undated section. This is the detailed record.
- **Parts list** — every part, with part number, source, price,
  and status (fitted / ordered / wanted / removed).
- **Gallery** — captioned photos from the build.
- **Changelog** — what changed on the page and the car, newest
  first.

## What the labels mean

**"As stated"** — a figure from a video, a forum, or memory that has
not been verified against the factory service manual. Treat it as a
lead, not a specification.

**"Verify in FSM"** — a factory figure the builder has not yet
confirmed in the factory service manual for that exact vehicle. It
is a factory claim, not a verified measurement.

A figure with no label is a verified factory figure or the builder's
own measurement.

## Following updates

New builds and major updates go into the **RSS feed**
(`feed.xml`, linked in the header of the library and every build
page). Subscribe in any feed reader — there is no account to make
and no platform in the middle. The feed is a plain file on the same
site; if the site moves, the feed moves with it.

## Using the information

This is educational information from real garage work. Confirm
every specification in the factory service manual for your exact
vehicle before you buy parts or cut metal. If a measurement is
borderline, that is a decision point — not a reason to force a build
together.
